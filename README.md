# GetProfile.me

**Instant Professional Presence**

Type your first + last name → Get a beautiful one-page website, custom domain, digital business card, and NFC-ready profile in seconds.

## Features
- Super simple onboarding (Name + LinkedIn)
- AI-generated short & effective one-page resume-style profile
- Automatic custom domain suggestion & registration (firstname-lastname.com preference)
- Unique permanent UID
- PWA Digital Business Card
- NFC tap sharing
- My Connections (people you shared with + who shared with you)
- Future: Send/receive money via UID

## Tech Stack
- Next.js 15 + TypeScript + Tailwind
- shadcn/ui
- LinkedIn OAuth
- AI (Grok / OpenAI)
- Domain registration API

**Running locally:** `npm run dev -- -p 5000`
