# GetProfile.me - UI Wireframes & Screens

## 1. Landing / Home
- Hero: "Your Name → Professional Presence"
- Big name input form (First + Last)
- Prominent LinkedIn button
- "Or build manually" link

## 2. Onboarding Flow
- Step 1: Name inputs
- Step 2: LinkedIn connect or manual form dialog
- Step 3: Profile preview (one-page resume style)
- Step 4: Domain selector + "Register" button

## 3. My Card (PWA Home)
- Clean business card view (photo, name, headline, tap to share)
- Quick actions: Share QR/NFC, View full profile

## 4. My Connections
- Tabs: "Shared with me" | "I shared with"
- Card grid with photo, name, notes, tags
- Search + filters

## 5. Profile Page (Public)
- Responsive one-page resume-style design
- Hero, About, Experience (short), Skills, Contact
- Share buttons

Design System: Modern, clean, professional (Tailwind + shadcn/ui). Dark mode supported.
